# Геймдизайн

## Игровой цикл

Главное меню → «Играть» → карта уровней → карточка уровня (цели, ходы,
награда, заряды помощников) → головоломка → экран результата (звёзды,
монеты, заряды, радостный помощник) → «Следующий уровень» или «На ферму» →
улучшения за монеты → новые участки (мельница — после уровня 6, загон —
после уровня 8, праздничное пугало — награда уровня 10).

Энергии, таймеров строительства и ожидания нет: можно играть сколько угодно.

Повторное прохождение: 25% награды уровня + 5 монет за каждый оставшийся ход.

### Звёзды

Детерминированно по итогам уровня (`LevelGoals.stars()`):

* 1★ — все цели выполнены;
* 2★ — и осталось не меньше «2★ запаса» ходов;
* 3★ — осталось не меньше «3★ запаса» ходов **и** выполнено дополнительное условие.

### Проверка проходимости (симуляция)

`tests/sim_levels.gd` играет каждый уровень жадным ботом **без помощников**
(бот не видит будущих падений). 40 партий на уровень:

| Уровень | Побед | 0★/1★/2★/3★ | Ходов в запасе (в среднем при победе) |
|---|---|---|---|
| 1 | 100% | 0 / 0 / 1 / 39 | 14.6 |
| 2 | 100% | 0 / 3 / 6 / 31 | 10.9 |
| 3 | 97% | 1 / 3 / 14 / 22 | 9.8 |
| 4 | 95% | 2 / 7 / 14 / 17 | 8.6 |
| 5 | 100% | 0 / 2 / 1 / 37 | 14.1 |
| 6 | 97% | 1 / 9 / 20 / 10 | 10.6 |
| 7 | 100% | 0 / 0 / 14 / 26 | 16.8 |
| 8 | 100% | 0 / 0 / 6 / 34 | 16.0 |
| 9 | 95% | 2 / 6 / 6 / 26 | 14.1 |
| 10 | 95% | 2 / 9 / 25 / 4 | 14.5 |

Все уровни проходимы без помощников и покупок. Настройка проводилась так:
сначала все уровни на 5 цветах оказались слишком лёгкими (бот заканчивал с
~18 ходами в запасе), затем большинство уровней переведены на 6 цветов; для
уровня 10 (нужна радужная ягода — совпадение 5 в линию) оставлено 5 цветов и
добавлены «толстые» сорняки, чтобы финал был самым насыщенным, но проходимым.

## Помощники

| Помощник | Способность | Старт | Где получить |
|---|---|---|---|
| Петя-Петушок | до 5 случайных обычных плодов | 2 | уровень 3, 3★ уровней 1/5/10, задания, магазин |
| Белка Рыжуля | убрать выбранный плод/усилитель/удар по сорняку | 2 | уровень 5, 3★ уровней 2/6/9/10, задания, магазин |
| Ёжик Колючка | взрыв 3×3 | 1 | уровень 7, 3★ уровней 4/8/10, задания, магазин |
| Пчёлка Жужа | +3 хода | 1 | уровень 9, 3★ уровней 3/7/10, задания, магазин |

Правила: ход не тратится; заряд списывается только в момент применения
(выбор клетки можно отменить без потери заряда); повторные касания во время
применения игнорируются; при нуле зарядов кнопка серая и предлагает магазин.

## Экономика фермы

Старт — 150 монет. Награды первых прохождений — 2150 монет + бонусы за ходы.
Полное восстановление фермы стоит ≈ 4000 монет, то есть ферма полностью
расцветает за 10 уровней плюс несколько повторов. Стоимости — в
`data/farm.json`.

| Объект | Уровни | Стоимость улучшений |
|---|---|---|
| Дом фермера | заброшенный → отремонтированный → уютный → дом мечты | 100 / 200 / 350 |
| Амбар | покосившийся → крепкий → нарядный → с силосной башней | 100 / 200 / 320 |
| Забор | сломанный → деревянный → белый штакетник | 60 / 140 |
| Главная грядка | заросшая → вскопанная → всходы → урожай | 80 / 160 / 260 |
| Яблоневый сад | пни → саженцы → зелёный сад → плодовый сад | 90 / 180 / 300 |
| Дорожки | заросшие → утоптанные → каменные | 60 / 130 |
| Фонари и клумбы | сломанный фонарь → фонари и клумба → праздничная площадь | 80 / 160 |
| Пруд | заросший → чистый → с мостками (утки) | 90 / 180 |
| Цветочная поляна | сухая → зелёная → цветущая с ульем | 70 / 150 |
| Сарай и склад | развалины → новый сарай → склад | 80 / 170 |

| Праздничное пугало | награда уровня 10 | — |

## Задания (первые шаги и достижения)

Первое совпадение, первый уровень, первая ракета, первое улучшение фермы,
первый помощник, первая корзина, первая радужная ягода, 10 звёзд,
5 улучшений фермы, все 10 уровней. Награды — заряды помощников или монеты,
забираются на экране «Помощники».
