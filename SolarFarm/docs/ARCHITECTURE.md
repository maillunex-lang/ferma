# Архитектура

## Сцены

| Сцена | Скрипт | Назначение |
|---|---|---|
| `MainMenu.tscn` | `scripts/ui/main_menu.gd` | логотип, монеты, прогресс 10 уровней, навигация |
| `LevelMap.tscn` | `scripts/ui/level_map.gd` | тропинка с 10 уровнями, карточка уровня перед стартом |
| `Match3Board.tscn` | `scripts/match3/match3_controller.gd` | головоломка |
| `LevelResult.tscn` | `scripts/ui/level_result.gd` | победа/поражение, звёзды, монеты, награды |
| `Farm.tscn` | `scripts/farm/farm_scene.gd` | ферма: камера, объекты, улучшения, животные |
| `HelperSelection.tscn` | `scripts/ui/helper_selection.gd` | помощники и задания |
| `Shop.tscn` | `scripts/ui/shop.gd` | бесплатный тестовый магазин (отдельный экран или окно поверх головоломки) |
| `Settings.tscn` | `scripts/ui/settings.gd` | громкость, эффекты, FPS, подсказки, сброс, об игре |

Интерфейс собирается в коде из общих блоков `UIKit` (палитра, «объёмные»
скруглённые кнопки, карточки, счётчики, анимации). Экраны-меню наследуют
`ScreenBase` (фон, верхняя панель с кнопкой «Назад» и монетами, прокрутка).

## Автозагружаемые модули

| Модуль | Ответственность |
|---|---|
| `SaveManager` | JSON-сохранение, контрольная сумма SHA-256, атомарная запись, резервная копия, версия формата и миграции |
| `GameManager` | переходы между сценами с затемнением, тосты и модальные окна, системная кнопка «Назад», пауза при сворачивании, безопасные отступы, применение настроек |
| `LevelManager` | данные уровней, открытие уровней, запись результата, выдача наград ровно один раз |
| `HelperManager` | заряды помощников (0–99), списание только при наличии |
| `EconomyManager` | монеты, каталог магазина, покупки через `PurchaseProvider`, защита от двойного нажатия |
| `FarmProgression` | объекты фермы, стоимость и условия улучшений, процент восстановления |
| `AchievementManager` | задания/достижения, прогресс событий, однократное получение наград |
| `AudioManager` | музыка с плавной сменой, пул из 10 плееров эффектов, шины Music и SFX |

## Головоломка: разделение логики и отображения

```
ввод (свайп/касание/помощник)
        │
        ▼
Match3Controller ──► BoardModel.try_swap / activate_at / helper_*   (чистая логика)
        │                     │
        │                     └─► { valid, phases: [ {cleared, weeds, effects, created,
        │                                              converted, moves, spawns, cascade}, … ] }
        ▼
анимация фаз по очереди (PieceView, FxLayer)  ──►  LevelGoals.apply_phase  ──►  Match3Hud.refresh
```

* `BoardModel` (`scripts/match3/board_model.gd`) не знает о сценах. Любое
  действие возвращает список фаз; при недопустимом ходе поле не меняется.
* Каскады обрабатываются в цикле; после 10 волн новые плоды подбираются так,
  чтобы не образовывать готовых совпадений, жёсткий предел — 40 волн. После
  хода, если ходов нет, добавляется фаза перемешивания (с гарантией хода и
  отсутствия готовых совпадений, с запасным вариантом перекраски).
* Сорняки — неподвижные препятствия: плоды «пролетают» за ними при падении;
  сорняк получает удар от совпадения в соседней клетке или от усилителя/помощника.
* `LevelGoals` считает цели, ходы и статистику (созданные усилители, глубину
  каскада, комбо) и выставляет звёзды детерминированно.
* `Match3Bot` — жадный игрок для тестов баланса; он не видит будущих
  случайных падений (симуляция с другим зерном генератора).

## Магазин и будущая монетизация

```
Shop UI ──► EconomyManager.purchase(id) ──► provider.purchase(product, done)
                                                  │
                         FreeTestProvider ────────┘  (сейчас: бесплатно, офлайн)
                         <будущий BillingProvider>   (реализует тот же интерфейс)
```

Для подключения реальной оплаты достаточно реализовать `PurchaseProvider`
(`price_label`, `is_test_mode`, `purchase`) и вызвать
`EconomyManager.set_provider(...)`. Экран магазина, выдача зарядов, лимит 99,
защита от повторных нажатий и журнал покупок не меняются. Сейчас нигде нет
кнопок, имитирующих реальную оплату: на каждой карточке — «Получить
бесплатно» и пометка «Тестовый режим».

## Ферма

Объекты описаны в `data/farm.json` (позиция, масштаб, названия уровней,
текстуры, стоимость, требуемый уровень). Для нового участка достаточно добавить
объект и нарисовать текстуры уровней. Цвет травы зависит от процента
восстановления, животные появляются по уровням построек. Камера: перетаскивание
одним пальцем, масштаб двумя пальцами или колесом мыши, границы мира.

## Производительность

* 60 FPS по умолчанию, ограничение до 30 в настройках (`Engine.max_fps`).
* Частицы — пул из 14 `CPUParticles2D`, переиспользуются; в режиме «Простые
  эффекты» частицы и тряска отключены.
* Звук — пул плееров, одинаковые звуки в пределах 40 мс не накладываются.
* Текстуры импортируются с мипмапами (чёткость при уменьшении), фоны в одном
  экземпляре на сцену. Сцены создают узлы один раз; при каскадах меняются
  только позиции и масштаб существующих спрайтов.
* При сворачивании приложение сохраняет прогресс и ставит головоломку на паузу.
